# Fieldwork Git workflow

Repository: https://github.com/ruthvik-01/web-scrapper.git, main branch. Run Git inside this app folder, which is an independent checkout. App contents are published directly at repository root.

Inspect task changes, run appropriate checks, stage only those changes, commit and push under the user's existing authorization. Keep generated outputs, credentials, dependencies and local archives out of commits. History replacement requires explicit authorization.

Do not add automated tool co-author trailers. The approved October 6 contributor correction removed Codebuff trailers with a guarded history replacement; prior history is backed up locally.
